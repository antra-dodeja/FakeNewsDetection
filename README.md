## 📌 Overview

An end-to-end machine learning system that classifies news articles as **Real** or **Fake** using Natural Language Processing (NLP) and classical ML algorithms. Built with Python, Scikit-learn, and Streamlit.

**Key highlights:**
- TF-IDF feature extraction (10,000 features, unigrams + bigrams)
- Logistic Regression & Naive Bayes comparison
- ~98% accuracy on the Kaggle Fake/Real News dataset
- Clean, interactive Streamlit web interface
- Automatic evaluation plots (confusion matrix, ROC curve, feature importance)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/fake-news-detection.git
cd fake-news-detection
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Download the dataset
1. Go to: https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
2. Download and unzip the archive
3. Place **`Fake.csv`** and **`True.csv`** in the project root folder

### 4. Train the model
```bash
python train_model.py
```
This will:
- Preprocess ~44,000 news articles
- Train Logistic Regression and Naive Bayes
- Pick and save the best model as `model.pkl` + `vectorizer.pkl`
- Save evaluation plots to `results/`

### 5. Launch the app
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`

## 🌐 Deploy for Free on Streamlit Cloud

1. Push the entire project (including `model.pkl` and `vectorizer.pkl`) to GitHub
2. Go to https://share.streamlit.io
3. Click **New App** → select your repo → set main file to `app.py`
4. Click **Deploy** ✅

> ⚠️ You **must** commit `model.pkl` and `vectorizer.pkl` to your GitHub repo. Run `train_model.py` locally first, then `git add model.pkl vectorizer.pkl`.

## 🧠 How It Works

```
Raw News Text
     ↓
[utils.py — Preprocessing]
  • Lowercase
  • Remove URLs, emails, HTML
  • Remove punctuation & digits
  • Remove stopwords (custom list, no NLTK needed)
     ↓
[TF-IDF Vectorizer]
  • 10,000 most important words
  • Unigrams + bigrams (word pairs)
  • Log (sublinear_tf) normalization
     ↓
[Logistic Regression / Naive Bayes]
  • Outputs: REAL (1) or FAKE (0)
  • Probability scores for confidence %
     ↓
[Streamlit UI]
  • Result card with color coding
  • Probability breakdown bars
  • Analysis history in sidebar
```
